# ResumeFlow Privacy Policy Draft

Last updated: 2026-08-18

ResumeFlow is a local-first browser extension that helps users fill job application forms with resume information and reusable text snippets.

## Data Stored By The Extension

ResumeFlow stores the following data in the user's browser local extension storage:

- Resume profile fields entered by the user.
- Reusable text snippets.
- Favorite and recent-use metadata for snippets.
- User-confirmed field mappings for specific website hostnames.
- Extension settings.

## Data Transmission

ResumeFlow does not operate a server and does not transmit resume data, snippets, mappings, or browsing content to the developer or to third-party analytics services.

When the user chooses to insert content into a webpage, the selected text is written into the active form field on that page. The target website may process that data according to that website's own privacy policy after the user submits the form.

## Permissions

ResumeFlow requests browser permissions only to provide its core functionality:

- Local storage for resume data, snippets, settings, and mappings.
- Access to the current webpage to detect editable form fields and insert user-selected content.
- Side Panel support for the extension interface.
- Clipboard write access when the user clicks a copy action.

## User Control

Users can edit, overwrite, or delete their resume content and reusable snippets within the extension. Uninstalling the extension removes the extension's local browser storage according to the browser's extension storage behavior.

## Remote Code, Ads, And Analytics

ResumeFlow does not load remote code, does not display ads, and does not include analytics SDKs.
